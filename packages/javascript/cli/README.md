# @lumis-sh/cli

Run the Lumis command line syntax highlighter with npm or npx.

```sh
npx @lumis-sh/cli --help
```

```sh
npm install -g @lumis-sh/cli
lumis --help
```

The `lumis` binary ships in a platform package that npm installs for you, so there is no download step and no install script. macOS, Linux (glibc and musl) and Windows are covered on both arm64 and x64.

See [https://docs.lumis.sh/cli](https://docs.lumis.sh/cli) for commands and options.
