Custom formatter

Interactive token inspector

A custom formatter that calls highlightIter() inside format() to build annotated HTML with per-token metadata you can inspect, including injected-language tokens.

Input HTML with injected JavaScript inside <script>.
Output Hoverable tokens with scope metadata and byte range annotations.
Use case Code walkthroughs, token inspection, and mixed-language UI hooks.
