# Lumis showcase

The [interactive showcase](https://lumis.sh/showcase/) runs each example in the browser with published Lumis packages. Every demo includes its source and live output.

## Live demos

- **Dual themes:** render light and dark themes together and switch with the reader's colour scheme.
- **Injected languages:** parse HEEx inside Elixir, Markdown inside doc strings, and other nested languages with their own grammars.
- **Markdown code fences:** highlight each fenced block in the language it names.
- **Template languages:** highlight both halves of ERB, EEx, HEEx, Vue, and Svelte templates.
- **Highlighted lines:** mark ranges with custom CSS or a theme colour.
- **Rainbow brackets:** colour bracket pairs by syntax-aware nesting depth.
- **250+ Neovim themes:** use themes generated from their original colorschemes.
- **Linked CSS:** emit scope class names instead of inline styles.
- **Custom headers:** wrap highlighted output with file names, toolbars, or copy buttons.
- **Custom formatters:** consume the token stream and return any output format.
- **Terminal output:** emit ANSI escape codes using the same themes.
- **BBCode output:** emit scoped tags for non-HTML destinations.
