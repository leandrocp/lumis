The Java package runs on Java 11 or later and needs no native library. It was previously published as `io.roastedroot:lumis4j`.

## Installation

```xml
<dependency>
  <groupId>sh.lumis</groupId>
  <artifactId>lumis</artifactId>
  <version>0.1.0</version>
</dependency>
```

Every language and theme ships in that jar.

## Basic usage

```java
import sh.lumis.Formatter;
import sh.lumis.Lang;
import sh.lumis.Lumis;
import sh.lumis.Theme;

var lumis = Lumis.builder().build();

var highlighter = lumis.highlighter()
    .withLang(Lang.JAVASCRIPT)
    .withTheme(Theme.CATPPUCCIN_FRAPPE)
    .withFormatter(Formatter.HTML_INLINE)
    .build();

var html = highlighter.highlight("const x = 1").string();
```

Building a `Lumis` takes a few seconds, so create one and reuse it. Calls on one `Lumis` are not synchronized, so use it from one thread at a time.

## Languages and themes

Languages and themes are available as enum constants:

```java
Lang.RUST
Lang.JAVASCRIPT
Lang.ELIXIR
Lang.PYTHON

Theme.CATPPUCCIN_FRAPPE
Theme.GITHUB_DARK
Theme.CATPPUCCIN_MOCHA
Theme.ONEDARK
```

`withLang` also takes a language name or alias such as `"c#"`, and `withTheme` takes a theme name. The language is not detected: without `withLang`, the code is highlighted as plain text. The default theme is `github_dark`.

## Custom themes

The Java package selects themes from the `Theme` enum and does not load theme JSON.
[Generate a theme from a Neovim colorscheme](/recipes/generate-theme-from-neovim-colorscheme)
covers JSON generation and source-license considerations, and shows how to
render HTML with the CLI as a build step.

## Formatter support

The Java package supports the following formatters: `TERMINAL` (the default), `HTML_INLINE`, `HTML_LINKED`, and `BBCODE`. `TERMINAL` and `HTML_INLINE` take a theme. `HTML_LINKED` and `BBCODE` emit class names and scope tags for external styling, so `build()` throws when a theme is set for them. Formatter options, multi-theme output, and custom formatters are not available.

## Results

`highlight` takes a `String` or UTF-8 bytes and returns a `LumisResult`. Read the output with `string()` or `bytes()`. `failure()` is true when highlighting failed, and `error()` returns the cause.
