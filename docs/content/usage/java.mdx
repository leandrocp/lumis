[`Lumis4J`](https://github.com/roastedroot/lumis4j) is a community-maintained Java runtime from [roastedroot](https://github.com/roastedroot). It has its own API and releases. Check the [Lumis4J documentation](https://github.com/roastedroot/lumis4j#readme) for supported features and version compatibility.

## Installation

```xml
<dependency>
  <groupId>io.roastedroot</groupId>
  <artifactId>lumis4j</artifactId>
  <version>0.0.7</version>
</dependency>
```

## Basic usage

```java
import io.roastedroot.lumis4j.core.Lang;
import io.roastedroot.lumis4j.core.Lumis;
import io.roastedroot.lumis4j.core.Theme;

var lumis = Lumis.builder().build();

var highlighter = lumis.highlighter()
    .withLang(Lang.JAVASCRIPT)
    .withTheme(Theme.CATPPUCCIN_FRAPPE)
    .build();

var html = highlighter.highlight("const x = 1").string();
```

## Languages and themes

Languages and themes are available as enum constants:

```java
Lang.RUST
Lang.JAVASCRIPT
Lang.ELIXIR
Lang.PYTHON

Theme.CATPPUCCIN_FRAPPE
Theme.GITHUB_DARK
Theme.CATPPUCCIN_MOCHA
Theme.ONEDARK
```

`withLang` and `withTheme` also take the name as a string. The language is not detected: without `withLang`, the code is highlighted as plain text. The default theme is `github_dark`.

## Custom themes

[Generate a theme from a Neovim colorscheme](/recipes/generate-theme-from-neovim-colorscheme)
covers JSON generation and source-license considerations. Lumis4J has its own
theme API; check its documentation for custom theme support in your version
rather than assuming it can load the generated JSON. The recipe also shows how
to render HTML with the CLI as a build step.

## Formatter support

lumis4j supports the following formatters: `TERMINAL` (the default), `HTML_INLINE`, `HTML_LINKED`, and `BBCODE`. `TERMINAL` and `HTML_INLINE` take a theme. `HTML_LINKED` and `BBCODE` emit class names and scope tags for external styling, so `build()` throws when a theme is set for them. Formatter options, multi-theme output, and custom formatters are not available.

## Results

`highlight` takes a `String` or UTF-8 bytes and returns a `LumisResult`. Read the output with `string()` or `bytes()`. `failure()` is true when highlighting failed.
