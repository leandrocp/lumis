<Tabs groupId="runtime" persist items={['JavaScript / TypeScript', 'Rust', 'Elixir', 'CLI']}>
  <Tab value="JavaScript / TypeScript">

```js
import '@lumis-sh/themes/css/catppuccin_frappe.css'
import {highlight} from '@lumis-sh/lumis'
import {htmlLinked} from '@lumis-sh/lumis/formatters'
import javascript from '@lumis-sh/lumis/langs/javascript'

const html = await highlight(
  'const x = 1',
  htmlLinked({language: javascript, preClass: 'demo'}),
)
```

  </Tab>
  <Tab value="Rust">

```rust
use lumis::{
    highlight, languages::Language, HtmlLinkedBuilder,
};

let html = highlight(
    "const x = 1",
    HtmlLinkedBuilder::new()
        .language(Language::Javascript)
        .pre_class(Some("demo".to_string()))
        .build()
        .unwrap(),
);
```

  </Tab>
  <Tab value="Elixir">

```elixir
Lumis.highlight!("const x = 1",
  formatter:
    {:html_linked,
     language: "javascript", pre_class: "demo"}
)
```

  </Tab>
  <Tab value="CLI">

```bash
lumis highlight index.js --formatter html-linked
```
