---
title: Browsers / CDN
description: Highlight code directly in Browsers with ESM CDN imports.
---



A browser loads only the parser packages you import, so import the one you need
from esm.sh next to Lumis. esm.sh serves the parser file next to the module,
and Lumis fetches nothing else.

```html
<script type="module">
  import {highlight} from 'https://esm.sh/@lumis-sh/lumis'
  import {
    htmlInline,
  } from 'https://esm.sh/@lumis-sh/lumis/formatters'
  import frappe from 'https://esm.sh/@lumis-sh/themes/catppuccin_frappe'
  import javascript from 'https://esm.sh/@lumis-sh/wasm-javascript'

  const output = document.getElementById('output')
  output.innerHTML = await highlight(
    'const x = 1',
    htmlInline({language: javascript, theme: frappe})
  )
</script>
<div id="output"></div>
```

See [Where parsers come from](/usage/javascript#where-parsers-come-from), and
[Custom resolvers](/usage/javascript#custom-resolvers) to fetch parsers at run
time instead.
