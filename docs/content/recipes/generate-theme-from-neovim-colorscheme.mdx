---
title: Generate a theme from a Neovim colorscheme
description: Generate a Lumis theme JSON file from an upstream Neovim colorscheme.
---



```bash
lumis themes generate \
  --url https://github.com/folke/tokyonight.nvim \
  --colorscheme tokyonight-night \
  --output tokyonight.json
```

The generated theme has a `license` field with the colorscheme's license as an
SPDX expression, read from the plugin's license file: `NONE` when the plugin
has no license file and `NOASSERTION` when the file matches no known license.
Check it before redistributing the theme.
