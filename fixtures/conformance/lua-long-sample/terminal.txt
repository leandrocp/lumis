[0m[38;2;248;248;242meatenBy[0m [0m[38;2;255;121;198m=[0m [0m[38;2;248;248;242mmyFavs[0m[0m[38;2;248;248;242m.[0m[0m[38;2;255;184;108manimal[0m  [0m[38;2;98;114;164m-- works! thanks, metatable[0m

[0m[38;2;98;114;164m--    self = Dog, but inheritance can change it.[0m
[0m[38;2;98;114;164m--    newObj gets self's functions when we set both[0m
[0m[38;2;98;114;164m--    newObj's metatable and self's __index to self.[0m
[0m[38;2;98;114;164m-- 5. Reminder: setmetatable returns its first arg.[0m
[0m[38;2;98;114;164m-- 6. The : works as in 2, but this time we expect[0m
[0m[38;2;98;114;164m--    self to be an instance instead of a class.[0m
[0m[38;2;98;114;164m-- 7. Same as Dog.new(Dog), so self = Dog in new().[0m
[0m[38;2;98;114;164m-- 8. Same as mrDog.makeSound(mrDog); self = mrDog.[0m

[0m[38;2;98;114;164m----------------------------------------------------[0m

[0m[38;2;98;114;164m-- Inheritance example:[0m

[0m[38;2;248;248;242mseymour[0m[0m[38;2;248;248;242m:[0m[0m[38;2;80;250;123mmakeSound[0m[0m[38;2;248;248;242m()[0m  [0m[38;2;98;114;164m-- 'woof woof woof'      -- 4.[0m

[0m[38;2;98;114;164m-- 1. LoudDog gets Dog's methods and variables.[0m
[0m[38;2;98;114;164m-- 2. self has a 'sound' key from new(), see 3.[0m
[0m[38;2;98;114;164m-- 3. Same as LoudDog.new(LoudDog), and converted to[0m
[0m[38;2;98;114;164m--    Dog.new(LoudDog) as LoudDog has no 'new' key,[0m

[0m[38;2;98;114;164m--    table is the first with the given key.[0m

  [0m[38;2;255;121;198mreturn[0m [0m[38;2;139;233;253msetmetatable[0m[0m[38;2;248;248;242m([0m[0m[38;2;248;248;242mnewObj[0m[0m[38;2;248;248;242m,[0m [0m[38;2;189;147;249mself[0m[0m[38;2;248;248;242m)[0m
